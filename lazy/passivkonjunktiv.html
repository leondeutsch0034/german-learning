§0出发前的三个公理Die drei Grundsätze — 后面每一页都靠它们推出来

德语的形式看着吓人，其实只有一条建筑法则：句子是「从左往右搭起来的」。左边那个词决定“什么时候 / 谁的视角 / 是否非现实”，右边那些词只是“什么意思”。

🧱 公理 ①　时态住在「第一个变位动词」身上
一个句子无论多长，第一个变位的动词（V1，第二位置那个）单独决定整句的时态。 其余所有动词都只是不定式或第二分词，形式固定，不随人称变。 例：hat … gebaut（完成） / wird … bauen（将来） / wurde … gebaut（被动过去）——变的永远是 hat/wird/wurde。
🧱 公理 ②　Partizip II = 「完成」和「被动」共用的语义包
PII（如 gebaut）本身不含时态，它只打包了两个信息：这件事已经发生/已经完成 + 主语是被处理的一方。 所以它既能进主动完成时（hat gebaut = 建好了），也能进被动（wird gebaut = 被建）。同一个 PII，两种用途。
🧱 公理 ③　时态往上叠，就往右边加不定式
一层：baut（现在）→ 两层：hat gebaut（完成）→ 三层：ist gebaut worden（被动完成）→ 四层：hat gebaut werden müssen（情态被动完成）。 每加一层，只有最左边那个词需要变位，右边的全部保持固定形状。这就是全篇唯一的“增长机制”。
💡 为什么先讲这三条？因为学习者的痛苦通常来自“把每个形式当成一个孤立的单词表去背”。而实际上：被动态 = 换两个词；虚拟式 = 换一个词干。整个专题就是把这两句话展开。
§1时态基座：六个时态的形式骨架Das Tempussystem — 一切推导的地基

先不动被动、也不动虚拟式，只看主动态的六个时态长什么样。请特别留意：左起第一列的“结构类型”——它是后面全部推导的接口。

橙色 = 变位动词（承载时态） 蓝色 = 第二分词 Partizip II 绿色 = 不定式 Infinitiv
时态骨架公式主动态示例（bauen · Der Architekt … das Haus）结构类型
Präsens
现在时		V1 现在时变位Der Architekt baut das Haus.建筑师建房子。单动词
Präteritum
过去时		V1 过去时变位Der Architekt baute das Haus.建筑师当时建了房子。单动词
Perfekt
现在完成时		haben/sein + PIIDer Architekt hat das Haus gebaut.房子已经建好了。双动词
Plusquamperfekt
过去完成时		hatte/war + PIIDer Architekt hatte das Haus gebaut.（在那之前）房子已建好。双动词
Futur I
第一将来时		werden + InfinitivDer Architekt wird das Haus bauen.建筑师将会建房子。双动词
Futur II
第二将来时		werden + PII + haben/seinDer Architekt wird das Haus gebaut haben.到时房子将会已建好。三动词
🔑 从这张表里读出三件事（后面全部推导都靠它们）：
1️⃣ Präsens / Präteritum 是「单动词」——时态直接长在实义动词上。这是最简单的一层，也是唯一“没有助动词可换”的一层。
2️⃣ Perfekt / Plusquamperfekt / Futur I 是「双动词」——左边一个助动词管时态，右边一个 PII 或不定式管词义。“管时态的那个词”就是后面被动要替换的槽位。
3️⃣ Futur II 是「三动词」——已经出现“werden + PII + haben”叠罗汉。它告诉我们：德语允许一直往右叠，叠到四层五层也不稀奇。
🖇️ 配套复习：本站 B1 语法 · 虚拟式B1 语法 · 被动语态 里有更细的动词变位与例句，本页负责把它们的逻辑顺序串成一条链。
📐 一条贯穿公理：句框结构（Satzklammer）
主句里 变位动词占第二位，其余动词全部挤在句末。
所以被动/虚拟式的所有“新词”都出现在句末那一堆里——看句子时先找第二位的那个词，它告诉你一切。
§2第一跳：主动 → 过程被动Vorgangspassiv — werden + Partizip II
2.1 先看“改写算法”，再看公式

把主动句改成被动句，只需要动三处地方。这三步是机械的，不用理解语义也能做对：

🔁 主动 → 被动 · 三步改写
第 1 步：宾格宾语（Akkusativ）→ 提到句首，变成第一格主语。 第 2 步：实义动词 → werden（由它承担全部时态变位）+ Partizip II（承载词义）。 第 3 步：原主语 → von + 第三格（施动者，可省略）；如果原句有第三格宾语，它原地不动。

Aktiv 主动

Der Architekt baut das Haus.
建筑师建这所房子。

Vorgangspassiv 过程被动

Das Haus wird (von dem Architekten) gebaut.
这所房子（被建筑师）建造着/正在被建。
2.2 核心递推公式
🧮 过程被动的万能公式
Passiv (时态 T) = werden 在 T 的变位 + Partizip II
右边那个 PII 永远不动（gebaut 就一直写 gebaut）。 整句的时态，100% 由 werden 决定。所以问题从“被动有六个时态吗”变成——“werden 的六个时态怎么写？”
2.3 一步步推：把 werden 推进六个时态

下面每一步都只做一件事：把上一行里 werden 的形式换成更高级的时态形式，PII 完全不动。

① Präsens→② Präteritum→③ Perfekt→④ Plusquamperfekt→⑤ Futur I→⑥ Futur II
时态werden 变成过程被动（bauen · Das Haus …）推导提示
PräsenswirdDas Haus wird gebaut.起点：werden 现在时
PräteritumwurdeDas Haus wurde gebaut.只把 wird → wurde
Perfektist … wordenDas Haus ist gebaut worden.⚠️ 第二跳：werden 自己也要变完成时
Plusquamperfektwar … wordenDas Haus war gebaut worden.ist → war，其余不动
Futur Iwird … werdenDas Haus wird gebaut werden.werden 的将来时 = wird + werden
Futur IIwird … worden seinDas Haus wird gebaut worden sein.把 Perfekt 形式再套上将来
⚠️ 唯一的坑：geworden → worden（去掉 ge-）
werden 的第二分词本来叫 geworden（实义“变成”时用它：Es ist kalt geworden. 天变冷了）。 但在被动完成时里，为了避免与“变成”混淆，去掉 ge-，写成 worden。 ✅ Das Haus ist gebaut worden.（这所房子被建好了）
❌ Das Haus ist gebaut geworden.（典型错句）
2.4 无人称被动（主语空缺也照样被动）
Es wird hier nicht geraucht. 这里不许吸烟。（没有“谁”在吸，也没有宾语可以提为主语）
Es wurde den ganzen Abend laut gelacht. 整个晚上都在大声笑。（es 只是占住第一位，句子也可以写成 Gestern wurde viel gelacht.）
💡 无人称被动只能出现在过程被动里，没有对应的状态被动——因为“一点结果状态都没有”。这条很常考。
§3第二跳：过程 → 状态被动Zustandspassiv — sein + Partizip II
过程被动回答的是「正在发生什么」；状态被动回答的是「结果是怎样的状态」。两者的差别，只在一个助动词上。

Vorgangspassiv（过程）— werden + PII

Die Tür wird geschlossen.
门正在被关上。（有人正在关 → 动作）

Zustandspassiv（状态）— sein + PII

Die Tür ist geschlossen.
门是关着的。（已经关好了 → 结果状态）
3.1 核心递推公式
🧮 状态被动的万能公式
Zustandspassiv (时态 T) = sein 在 T 的变位 + Partizip II
把过程被动公式里的 werden 整体换成 sein——结构不变，只换助动词。 PII 还是那个 PII，一个字都不用改（geschlossen 永远是 geschlossen）。
3.2 六个时态（sein 走一遍六个时态）
时态sein 变成状态被动（schließen · Das Geschäft …）使用频率
PräsensistDas Geschäft ist geschlossen.商店关着门。⭐⭐⭐ 极常用
PräteritumwarDas Geschäft war geschlossen.商店当时关着。⭐⭐⭐ 极常用
Perfektist … gewesenDas Geschäft ist geschlossen gewesen.商店（那时）一直是关着的。⭐ 少见
Plusquamperfektwar … gewesenDas Geschäft war geschlossen gewesen.（更早前）商店是关着的。⭐ 少见
Futur Iwird … seinDas Geschäft wird geschlossen sein.商店将会是关着的。⭐⭐ 书面
Futur IIwird … gewesen seinDas Geschäft wird geschlossen gewesen sein.到时商店将已关着。⚪ 极少
🔎 对照着记：两个被动在完成时里的“标志词”完全不同——
过程被动完成时出现 worden：ist gebaut worden；
状态被动完成时出现 gewesen：ist gebaut gewesen。
看到 worden 就是过程，看到 gewesen 就是状态——这是一秒钟的判断法。
3.3 四种判别测试：到底是过程还是状态？
测试过程被动 Vorgang状态被动 Zustand
能否插入 gerade（正在）✅ Die Tür wird gerade geschlossen. 门正在被关❌ Die Tür ist gerade geschlossen.（语义不通）
能否加 von + Dativ（施动者）✅ … wird von ihm geschlossen.❌ 状态被动不能带 von-短语
完成时标志词wordengewesen
能否用 bleiben 替换 sein❌✅ Die Tür bleibt geschlossen. 门保持关着
能否加 seit + 时间❌✅ … seit gestern geschlossen. 从昨天起就关着
⚠️ 最容易搞混的一类：sein + PII 到底是「状态被动」还是「完成时」？
• 及物动词的 PII 跟在 sein 后面 → 状态被动：Die Tür ist geschlossen.（门是关着的）
• 不及物动词（尤其表示“移动/状态变化”的）的 PII 跟在 sein 后面 → 那是它的 Perfekt 完成时，跟被动毫无关系：Er ist gekommen.（他来了）／Das Kind ist eingeschlafen.（孩子睡着了）
👉 认出“是哪个动词的 PII”，就能一秒定性。
🧊 不是所有动词都能有状态被动。只有“动作做完后会产生一个持续结果状态”的动词才有：schließen → geschlossen ✓、bauen → gebaut ✓。
而没有结果状态的动词（持续类：betreuen、dauern），或本身就无宾语的无人称被动，都只说过程、不说状态。
🎓 一个高价值的视角：状态被动 ≈ 形容词
状态被动里的 PII，其实就相当于一个形容词：Das Geschäft ist geschlossen. ≈ Das geschlossene Geschäft。
所以它能被 noch / schon / seit / bleiben 修饰，也能和 offen, sauber 这类形容词并排使用。理解这一点，状态被动就不需要“背”了。
§4第三跳：情态动词进入被动Passiv mit Modalverben — 三动词结构

“必需被… / 能够被… / 应该被…”——只要在被动上再加一个情态动词，就得到德语最常用的正式表达之一。

4.1 核心递推公式
🧮 情态被动的万能公式
Modalpassiv (时态 T) = 情态动词在 T 变位 + Partizip II + werden（不定式）
跟纯被动的区别只有一处：最左边多了一个情态动词，它抢走了“变位权”。 而原来的 werden 因为交出了变位权，就退回成不定式 werden，被挤到句子最末尾。 所以顺序永远是：情态动词 + PII + werden。
Das Haus muss gebaut werden. 这所房子必须被建造。（= 必须建这所房子）
4.2 一步步推：情态动词走六个时态
时态情态被动（müssen · Das Haus …）推导提示
PräsensDas Haus muss gebaut werden.muss 现在时，其余照抄
PräteritumDas Haus musste gebaut werden.muss → musste
PerfektDas Haus hat gebaut werden müssen.⚠️ 大坑：Ersatzinfinitiv，见 4.3
PlusquamperfektDas Haus hatte gebaut werden müssen.hat → hatte
Futur IDas Haus wird gebaut werden müssen.wird + 整个不定式组
Futur IIDas Haus wird gebaut worden sein müssen.极少用，认得即可
4.3 硬坑：Ersatzinfinitiv（替代不定式）
⚠️ 情态动词的完成时，不用 PII，用不定式
按理说“必须”的完成时应该是 hat … gemusst。但德语里，只要还有一个不定式跟在后面，情态动词就必须退回成不定式 müssen，而不是 gemusst。 ✅ Das Haus hat gebaut werden müssen.
❌ Das Haus hat gebaut werden gemusst. 同样的规则适用于 können, dürfen, sollen, wollen, mögen，以及 lassen, sehen, hören, fühlen, brauchen。
例：Ich habe ihn kommen sehen.（我看见他来了）／ Er hat sich die Haare schneiden lassen.
⚠️ Ersatzinfinitiv 带来的著名语序异常（从句里）：
普通从句里，变位动词应该在最末：…, dass das Haus gebaut werden muss.（现在时 ✓）
但一变成完成时，变位动词 hat 会跳到整套不定式的前面：
✅ …, dass das Haus hat gebaut werden müssen.
❌ …, dass das Haus gebaut werden müssen hat.
👉 这是德语语法里最公认的“不规则中的不规则”，B2/C1 写作里用对一次就是加分项。
4.4 语义辨析：nicht 放在哪，意思差很远

nicht 否定“义务”

Das Haus muss nicht gebaut werden.
这房子不必被建。（建也可以，不建也行）

nicht 否定“许可”

Das Haus darf nicht gebaut werden.
这房子不许被建。（禁止）
💡 muss nicht = 不必；darf nicht = 不准；kann nicht = 不可能/不能。中文都容易说成“不能”，德语却分得很清楚。
4.5 顺带一网打尽：被动的替代形式（Passiversatz）

德语正式文体（论文、新闻、说明书）常把被动“藏”在别的结构里。认出它们 = 阅读提速 + 写作升级。

替代形式例子等于
sein + zu + InfinitivDie Rechnung ist bis Freitag zu bezahlen.= Die Rechnung muss bis Freitag bezahlt werden.（必须）
= Die Rechnung kann bis Freitag bezahlt werden.（能够）
sich lassen + InfinitivDas lässt sich leicht erklären.= Das kann leicht erklärt werden.（能被…）
-bar 形容词Der Text ist lesbar.= Der Text kann gelesen werden.（可读的）
bekommen / erhalten + PIIEr bekommt das Buch geschenkt.第三格宾语的被动（= 他收到这本书作为礼物）
功能动词结构Beachtung finden= beachtet werden（受到重视）
bleiben / stehen / liegen + PIIDer Kuchen bleibt unberührt.状态持续（一直没被动过）
🖇️ 情态动词本身的完整体系（主观用法、推测、双不定式）见本站 B2 语法 · 情态动词六层体系——本节只取它与被动交叉的那一部分。
§5第四跳：虚拟式的推导Konjunktiv I / II — 换词干，不换词尾

虚拟式不是“另一种动词”。它只是：把词干换掉，词尾照旧用同一套。Konjunktiv I 和 II 的差别，只在词干取自哪个时态。

5.1 统一公式：一套词尾 + 两种词干
人称共用词尾KI 例（machen 现在词干 mach-）KII 例（haben 过去词干 hatt- 加变音）
ich-emachehätte
du-estmachesthättest
er / sie / es-emachehätte
wir-enmachenhätten
ihr-etmachethättet
sie / Sie-enmachenhätten
🧮 词干从哪来？——这是 KI 与 KII 唯一的区别
Konjunktiv I：词干 = 不定式去掉 -en（现在时词干）。kommen → komm- → er komme Konjunktiv II：词干 = Präteritum 词干，能变音就变音。kam → käm- → er käme；hatte → hatt- → hätte 这就是全部。德语用“用过去标记非现实”的隐喻——就像中文说“要是当时有钱就好了”，用时间上的距离表达现实上的距离。
⚠️ 为什么还需要 würde + 不定式？
规则动词（machen）的 KII 词干 = 过去词干 machte-，加词尾后 er machte——和过去时一模一样，无法区分“这是过去发生的事实”还是“这是不现实的假设”。
于是德语演化出 würde + Infinitiv 作为明确的非现实标记。
👉 强变化动词因为能变音（hatte → hätte），自身形式就够用，不必借 würde。
5.2 关键认知：虚拟式没有六个时态，只有两个时间层
🧠 学习者最大的误解，就是以为“虚拟式也要走完六个时态”。不需要。
虚拟式只区分：① 与说话同时（现在/将来） 和 ② 先于说话（过去）。将来时直接用 würde + 不定式即可。
动词类型① 现在层 · Gegenwart（非现实的现在/将来）② 过去层 · Vergangenheit（非现实的过去）
普通动词 machener würde machen ／ 书面：er machteer hätte gemacht
seiner wäreer wäre gewesen
habener hätteer hätte gehabt
情态动词 könnener könnte (… machen)er hätte … machen können
过程被动es würde gebaut werdenes wäre gebaut worden
💡 注意最后一行的规律：过去层的虚拟式，把时间信息交给 hätte / wäre，真正的动词退回不定式或 PII——这跟 §1 的“时态住在第一个变位动词身上”完全是同一个道理。你已经在用的，还是那条公理。
5.3 Konjunktiv I 的形态与用法（间接引语专用）
时间层形式（以 sagen 为例）说明
现在er sage / er sei / er habe词干 + e 词尾
过去er habe gesagt / er sei gekommenKI 没有 Präteritum，用完成时代替
将来er werde sagen用 werden 的 KI
⚠️ KI 的替换规则：如果 KI 形式和直陈式长得一样（如复数 sie kommen 的 KI 也是 kommen），就必须改用 KII（sie kämen）或 würde 形式（sie würden kommen），否则读者分不清是转述还是事实。
⚠️ 唯一不规则的 KI：sein → ich sei / du sei(e)st / er sei / wir seien / ihr sei(e)t / sie seien。
5.4 Konjunktiv II 的六大功能（按“与现实的距离”排列）
#功能例子中文
1礼貌请求Würden Sie mir bitte helfen?您能帮帮我吗？
2非现实愿望Hätte ich doch mehr Zeit!要是我有更多时间就好了！
3非现实条件Wenn ich Zeit hätte, würde ich mitkommen.如果我有时间，我就一起来。
4委婉建议Du solltest früher schlafen.你最好早点睡。
5非现实比较Er tut, als ob er alles wüsste.他装作什么都知道。

§6第五跳：被动 × 虚拟式（终极交叉）Passiv im Konjunktiv — 把公理①再走一遍
到这里，两条线合流了。交叉的方法只有一句话：
🧮 被动虚拟式的万能公式
把被动句里的「第一个变位动词」换成虚拟式，其余一个字都不动。
被动句里第一个变位动词是谁？—— 过程被动是 werden，状态被动是 sein，情态被动是情态动词。 把它们分别虚拟化：werden → werde / würde；sein → sei / wäre；muss → müsse / müsste。 后面的 PII、werden、worden 全部保持原样。

剩下那些 gebaut、worden、gewesen、werden、müssen —— 一个字都没变。这就是公理①在起作用的证据。
6.2 “双 werden”是怎么回事？
Das Haus würde gebaut werden. 这所房子（如果条件满足）就会被建。
一句话里出现两个 werden，别慌——它们不是一个词的两个身份，而是分工明确的两个人：
• 前面的 würde = 变位动词，只负责「非现实」（KII 的标记）；
• 后面的 werden = 不定式，只负责「被动」（被动语态的标记）。
👉 去掉任何一个都会坏掉：没有 würde 就不是虚拟，没有 werden 就不是被动。
6.3 实战：新闻报道里的间接引语被动（最常考）
Aktiv（直接引语）：Der Minister sagte: „Wir haben das Gesetz verabschiedet.“ 部长说：“我们已经通过了这项法律。”
KI + 被动（记者转述）：Der Minister sagte, das Gesetz sei verabschiedet worden. 部长说，该法律已被通过。（记者不表态，只转述）
KI + 情态被动：Er sagte, das Gesetz müsse noch geprüft werden. 他说，该法律还须被审查。
💡 德语新闻体的中立性就藏在这里：内容是被动的（谁通过的不重要），态度是被虚拟的（记者不站队）。两个语法工具叠加使用。
6.4 非现实条件 + 被动（考试写作高分结构）
Wenn das Haus früher gebaut worden wäre, hätten wir jetzt mehr Platz. 要是这所房子当初早点被建好，我们现在就有更多空间了。
Wenn die Aufgabe rechtzeitig erledigt worden wäre, wäre das Projekt nicht gescheitert. 如果任务当时被及时完成，这个项目就不会失败了。
✅ 可复制的句型模板：Wenn + [PII] + worden wäre, hätte/wäre + …
= “要是当时（被）……了，现在就……” —— 议论文里表达“经验教训”的黄金句式。

7.1 终极总表：同一个动词 bauen · 六时态 × 四形态
时态 ① Aktiv 主动 ② Vorgangspassiv 过程被动 ③ Zustandspassiv 状态被动 ④ Modalpassiv 情态被动
Präsens Der Architekt baut das Haus. Das Haus wird gebaut. Das Haus ist gebaut. Das Haus muss gebaut werden.
Präteritum Der Architekt baute das Haus. Das Haus wurde gebaut. Das Haus war gebaut. Das Haus musste gebaut werden.
Perfekt Der Architekt hat das Haus gebaut. Das Haus ist gebaut worden. Das Haus ist gebaut gewesen. Das Haus hat gebaut werden müssen.
Plusquamperfekt Der Architekt hatte das Haus gebaut. Das Haus war gebaut worden. Das Haus war gebaut gewesen. Das Haus hatte gebaut werden müssen.
Futur I Der Architekt wird das Haus bauen. Das Haus wird gebaut werden. Das Haus wird gebaut sein. Das Haus wird gebaut werden müssen.
Futur II Der Architekt wird das Haus gebaut haben. Das Haus wird gebaut worden sein. Das Haus wird gebaut gewesen sein. Das Haus wird gebaut worden sein müssen.
📌 读这张表的正确方式：不要横着一行一行背，要竖着看一列——每一列内部的变化，永远只发生在最左边那个变位动词上，后面的部分整列几乎不动。看懂这一点，这张表就从“24 个句子”压缩成了“4 条公式”。

7.3 心法十二条（背下这十二句，等于背下整个专题）
① 一个句子只有一个“变位动词”时态、语气、人称全在它身上。找句子先找它。
② Partizip II 不背时态它只表示“完成 + 被处理”，时态永远交给左边的助动词。
③ 复杂 = 往右叠每加一个语法层，就往句末多放一个不定式或分词。
④ 被动只换两处实义动词 → PII；助动词 → werden（过程）/ sein（状态）。
⑤ 过程看“发生”，状态看“结果”Vorgang 能加 gerade 和 von；Zustand 能加 seit 和 bleiben。
⑥ worden 只属于过程被动完成时的过程被动有 worden，状态被动有 gewesen，两者不可能同时出现。
⑦ werden 的 PII 有两副面孔实义“变成”用 geworden；被动助动词用 worden。
⑧ 情态 + 被动 = 情态 + PII + werden情态动词抢走变位权，werden 退成不定式排到最后。
⑨ 情态动词的完成时用不定式Ersatzinfinitiv：hat … müssen，绝不是 hat … gemusst。
⑩ 虚拟式只换词干KI 用现在词干，KII 用过去词干（能变音就变音），词尾同一套。
⑪ 虚拟式只有两个时间层现在层（würde/hätte/wäre + …）和过去层（hätte/wäre + PII），将来用 würde 顶。
⑫ 被动虚拟式 = 把第一个变位动词虚拟化werden→werde/würde，sein→sei/wäre，muss→müsse/müsste，其余照抄。
7.4 易错清单（阅卷老师最爱扣分的 10 处）
❌ 常见错句✅ 正确错在哪
Das Haus ist gebaut geworden.Das Haus ist gebaut worden.被动完成时去掉 ge-
Das Haus wird gebaut geworden.Das Haus wird gebaut.现在时被动只有一个 werden
Das Haus hat gebaut werden gemusst.Das Haus hat gebaut werden müssen.Ersatzinfinitiv
Die Tür ist von ihm geschlossen. (= 状态)Die Tür ist geschlossen. / Die Tür wird von ihm geschlossen.状态被动不能带施动者
Er ist geschlafen.（想表达状态被动）Er hat geschlafen.（= 完成时）不及物动词没有状态被动
Wenn ich Zeit habe, würde ich kommen.Wenn ich Zeit hätte, würde ich kommen.非现实条件要用 KII
Er tat, als ob er alles weiß.Er tat, als ob er alles wüsste.als ob 后要用 KII
Der Minister sagte, das Gesetz ist verabschiedet worden.…, das Gesetz sei verabschiedet worden.间接引语用 KI
Das Projekt wird bis Juni beendet geworden sein.Das Projekt wird bis Juni beendet worden sein.Futur II 被动 = wird + PII + worden sein
Ich hätte es machen können gehabt.Ich hätte es machen können.KII 过去层不需要再加 gehabt
📌 第 6 条和第 9 条其实是同一个病根：把 werden 的两个身份搞混了。实义“变成”的 PII 是 geworden，被动助动词的 PII 是 worden。凡是“被……”的完成时，一律 worden。
§8自测 20 题Selbsttest — 先自己写，再点“显示答案”

建议：拿纸先写完整句，再展开答案对照。错的题回到对应小节重读那一段，不要只记答案。

1Man baut hier ein neues Krankenhaus. → 改成过程被动（现在时）。
Hier wird ein neues Krankenhaus gebaut.宾语 ein neues Krankenhaus → 主语；baut → wird + gebaut；Man 省略。
2Die Firma stellte 200 Leute ein. → 过程被动（过去时）。
200 Leute wurden (von der Firma) eingestellt.可分动词 einstellen 的 PII = eingestellt；stellte → wurde。
3Man hat die Straße gesperrt. → 过程被动（现在完成时）。
Die Straße ist gesperrt worden.⚠️ 完成时的被动用 worden，不是 geworden。
4Man hatte das Problem schon gelöst. → 过程被动（过去完成时）。
Das Problem war schon gelöst worden.hatte → war，PII 与 worden 照抄。
5Man wird die Ergebnisse morgen veröffentlichen. → 过程被动（将来时）。
Die Ergebnisse werden morgen veröffentlicht werden.Futur I 被动 = werden（变位）+ PII + werden（不定式）；主语复数所以是 werden…werden。
6Man wird das Projekt bis Juni beendet haben. → 过程被动（将来完成时）。
Das Projekt wird bis Juni beendet worden sein.Futur II 被动 = wird + PII + worden sein。
7“商店关着门。” → 状态被动（现在时）。
Das Geschäft ist geschlossen.强调“结果状态”→ 状态被动用 sein + PII。
8“昨天商店是关着的。” → 状态被动（过去时）。
Das Geschäft war gestern geschlossen.ist → war，其余不变。
9“这所房子必须被建造。” → 情态被动（现在时）。
Das Haus muss gebaut werden.情态动词变位 + PII + werden（不定式，句末）。
10“这所房子当时必须被建造。” → 情态被动（过去时）。
Das Haus musste gebaut werden.muss → musste，其余照抄。
11“这所房子（当时）不得不被建造。” → 情态被动（现在完成时）。
Das Haus hat gebaut werden müssen.⚠️ Ersatzinfinitiv：情态动词用不定式 müssen，不用 gemusst。
12把上句改成从句：…, dass das Haus … （完成时）。
…, dass das Haus hat gebaut werden müssen.⚠️ Ersatzinfinitiv 的语序异常：hat 跳到整套不定式之前，而不是放在最末。
13Der Text kann leicht gelesen werden. → 用 -bar 形容词改写。
Der Text ist leicht lesbar.kann … werden ↔ -bar 形容词，是最常见的被动替代形式之一。
14Das lässt sich leicht erklären. → 还原成情态被动。
Das kann leicht erklärt werden.sich lassen + Inf. = können + PII + werden。
15Die Rechnung muss bis Freitag bezahlt werden. → 用 sein + zu + Inf. 改写。
Die Rechnung ist bis Freitag zu bezahlen.sein + zu + 不定式 = 必须被 / 能够被。
16“要是这所房子当初早点被建好，我们现在就有更多空间了。”（用 KII + 被动）
Wenn das Haus früher gebaut worden wäre, hätten wir jetzt mehr Platz.KII 过去层被动 = wäre + PII + worden；主句 hätte 型。
17“您能帮帮我吗？”（礼貌）→ Konjunktiv II
Könnten Sie mir bitte helfen? / Würden Sie mir bitte helfen?KII 表礼貌：könnten / würden + 不定式。
18Der Minister sagte: „Das Gesetz wurde verabschiedet.“ → 用 KI 转述（用被动）。
Der Minister sagte, das Gesetz sei verabschiedet worden.间接引语用 KI + 被动完成时：sei + PII + worden。
19“这所房子（据说）必须被审查。”→ KI + 情态被动
Das Haus müsse geprüft werden.情态动词的 KI = müsse；werden 保持不定式。
20改错：Das Haus ist gebaut geworden.
Das Haus ist gebaut worden.被动完成时，werden 的 PII 去掉 ge- 写成 worden。geworden 只用于实义“变成”。
