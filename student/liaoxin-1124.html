廖欣 · 介词 + 第三格

Erkan 与旅行对话 · 手机短信 · Fatih Akin · war / waren · 换音动词 · 方位 · 介词 + 第三格
练习 每句都能点 🔊 听 每天 10 分钟
今天新加了一个概念：介词 + 第三格。板书上 zu / in / auf / an / mit / bei 后面，冠词一律变三格：dem / dem / der / den。
老师说的那句话就是这一页的用法：把之前零散的语法点反复归纳，慢慢编成一张网——第三步就是这张网。
卡点一 · 介词定三格不用猜：介词后面先看名词是男、女还是中性，再套 dem / dem / der / den。
卡点二 · 动词两条线sein 的过去时 war / warst / waren；换音动词只在 du 和 er/sie/es 变音（sprechen、essen、nehmen、werden）。
卡点三 · 说位置Wo ist denn das? 问「在哪儿」；Wo liegt denn Peking? 问「坐落在哪儿」。答句用 im Norden von / nördlich von。
① 听先点 🔊 听对话，只听，不跟。
② 跟按「块」跟读，注意句尾是升还是降。
③ 做先读完整句，再做题；做错就看下面的讲解。

三格这一行就是今天要反复用的：dem / dem / der / den。看到介词，先在心里把冠词换成这一行。
口诀还是那两句：1 是 1（Ich bin der Lehrer / Er wird Lehrer）；1 做 4（Ich sehe den Lehrer）；加了介词就进三格（Ich spreche mit dem Lehrer）。

新概念 · 介词 + 第三格 板书：zu / in / auf / an / mit / bei
德语里有一批介词，后面永远跟第三格，不用判断方向。aus · bei · mit · nach · seit · von · zu 这七个是最常见的；其中 von 表示「谁的」：Das Buch ist von Thomas。
板书上的 in / an / auf 是「在哪里」时用三格：im Norden、am Bahnhof、auf dem Tisch。表示「去哪里」时它们会用四格——那是下一步的内容，今天先记「原地用三格」。

第四步 · 方位：在……的北部 / 在……以北 板书赣州那组 + 教材 S.51
同一个意思有两种说法：im Norden von Jiangxi（在江西的北部）＝ nördlich von Jiangxi（在江西以北）。im 就是 in + dem，所以它后面也是三格。教材 S.51 还有 in der Mitte von（在……中部）和 in der Nähe von（在……附近）。
